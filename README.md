
# 卒業研究: 不確実な予約を考慮した観光戦略の最適化

## 概要
本リポジトリは，イベント終了後の不確定な状況下で「予約」を扱いながら観光地を効率良く巡回する戦略を探索するための研究用実装です。
遺伝的アルゴリズム（GA）をベースに，各種変異・交叉・局所探索を組み合わせて最適または良好な巡回経路を探索します。実験用のデータ生成・出力パイプラインも含まれます。

## 特長
- GA（遺伝的アルゴリズム）を用いた探索
- 複数の変異・交叉手法の実装（例: `mutation_random.c`, `mutation_swap.c`, `crossover_twopoint.c`）
- 局所探索モジュール（`localSearch.c`, `localSearchBinary.c`, `localSearchUltimate.c`）
- 入出力・実験ログの管理（`output/` ディレクトリ）

## 依存環境
- Cコンパイラ（`gcc` や Visual Studio のコンパイラ等）
- 標準的な UNIX ライクなツールがあると便利（`bash` 等）。Windows では WSL を推奨。

## ファイル構成（主なもの）
- `main.c`：メイン実行ファイル（実験のパラメータ設定と実行フロー）
- `initialize_population.c`：初期個体生成
- `calculate_fitness.c`：適応度計算
- `crossover_twopoint.c`：二点交叉
- `mutation_*.c`：変異実装群
- `localSearch*.c`：局所探索実装群
- `makedata.c` / `runMakeData`：実験用データ生成スクリプト
- `o-sakaFoodsX.txt`：サンプル入力データ（配置・距離など）
- `output/`：実行結果（ログ・最良解など）

## ビルド方法（例）
簡単にコンパイルする場合（同ディレクトリで）:

```bash
gcc -O2 -std=c99 *.c -o ga
```

Windows の場合は出力が `a.exe` になることがあります。ビルドに Makefile が無い場合は上記のようにまとめてコンパイルしてください。

## 実行方法（例）
- 生成したバイナリを実行します:

```bash
./ga
```

または（Windows）:

```powershell
.\a.exe
```

実行時のパラメータや出力先は `main.c` 内の設定で調整できます。結果は `output/` 以下に保存されます。

## データ生成と実験の流れ
1. 必要に応じて `makedata.c` / `runMakeData` を使い実験用データを作成する。
2. `gcc` 等でコンパイルする。
3. バイナリを実行し，`output/` に出力されるログを確認する。

## 注意事項
- 本実装は研究・実験用途を目的としており，汎用的なライブラリ化やエラーハンドリングは最小限です。用途に合わせてコードを整備してください。
